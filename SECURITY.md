# Security Policy

SSB takes the security of its software products and services seriously,
including source code repositories managed through the `statisticsnorway`
GitHub organization.

## Reporting a Vulnerability

Please do not open a public issue for a suspected security vulnerability.
Report it using the [GitHub Private vulnerability reporting tool](https://github.com/statisticsnorway/metamapper-testdata-generator/security/advisories).

Do not include passwords, access tokens, service-account keys, or other
secrets in issues, pull requests, notebooks, or repository configuration.
